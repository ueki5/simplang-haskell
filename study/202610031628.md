[SlotResultの使われ方について]
色々な型があって見通しが悪いので、整理したかった。
```haskell
type SlotResult = Either String (Either Slot (Maybe Type))
type Evidence = [(Slot,          Either Slot (Maybe Type))]
type LocalEnv = [Map String     (Either Slot        Type)]
lookupLocal :: String -> LocalEnv -> Maybe                                               (Either Slot        Type)
setLocal :: String ->                                                                     Either Slot        Type -> LocalEnv -> LocalEnv
addressOfSlot :: Map String FnDecl -> ResolvedSlots -> LocalEnv -> Expr -> Either String (Either Slot        Type)
paramLocalScope :: ResolvedSlots -> String -> [(String, Maybe Type)] -> Map String       (Either Slot        Type)
fnDeclEvidence :: Map String FnDecl -> ResolvedSlots -> FnDecl -> Either String [(Slot,   Either Slot (Maybe Type))]
```

[調査方針]
SlotResultを返却するのは、resolveExprTypeとchainSlotのみ。
また、chainSlotを呼び出しているのはresolveExprTypeのみ。
従って、SlotResultがどのように使われているのかは、resolveExprTypeを調査すればよい。

[resolveExprTypeの呼び出し元を調査]
- addressOfSlot (Either String (Either Slot Type)) から呼び出した時
 この関数自体、resolveExprTypeからしか呼び出されない為、処理は内部に閉じている。
 このため、用途自体は他の呼び出し関数から判断の事（callEvidence, collectEvidenceStmts, fnDeclEvidence）
 処理自体は式の型により以下の通り。
  - Var
    変数環境(LocalEnv)から変数の状態（Either Slot Type）を返却、なければエラー
  - Deref
    resolveExprTypeで型を取得し、変換して返却
    取得：               Either Slot (Maybe Type) 
    返却：Either String (Either Slot        Type )
    - Left slot -> Right (Left slot)
    - Right (Just (TPtr inner)) -> Right (Right inner)
    - Right (Just other) -> Left エラー（不正な型）
    - Right Nothing -> Left エラー（型が未解決）
- callEvidence (Either String Evidence) から呼び出した時
  - 式中のCallからParamSlotの証拠を返却する。
- collectEvidenceStmts (Either String (LocalEnv, Evidence)) から呼び出した時
  - SLetInferredから型を導出してLocalEnvを返却
  - Return文の返却式からReturnSlotの証拠を返却
- fnDeclEvidence から呼び出した時
  - 末尾式からReturnSlotを返却

[結論]
単純に型が長くなって読みづらい為、あった方がよい。

```変更前
chainSlot :: SlotResult -> (Maybe Type -> SlotResult) -> SlotResult
chainSlot r k = do
  v <- r
  case v of
    Left slot -> Right (Left slot)
    Right ty -> k ty
```
```変更後
chainSlot :: Either String (Either Slot (Maybe Type))-> (Maybe Type -> SlotResult) -> Either String (Either Slot (Maybe Type))
chainSlot r k = do
  v <- r
  case v of
    Left slot -> Right (Left slot)
    Right ty -> k ty
```
