[SlotResultの使われ方について]
  型 :Either String (Either Slot (Maybe Type))

SlotResultは、resolveExprTypeの戻り値としてのみ作成される。
また、resolveExprTypeは入力式の型を解決するものであるが、それが変数
ロジックだけを見ると、スロットだけでなく変数も混ざりそうに見えるが、スロット限定の型のはず。
そこで、「変数が混ざるケースは実際には呼び出されない(全部スロット)のではないか？」という仮説を立て、 resolveExprTypeの呼び出し元を調査

１）addressOfSlot (Either String (Either Slot Type)) から呼び出した時
 resolveExprTypeの型：Either String (Either Slot (Maybe Type))
 自身の型           ：Either String (Either Slot        Type)
 Just (TPtr inner) → Right inner 
 Just _            → Left (ポインタ化できない)
 Nothing           → Left (型が未定義)
  ①addressOfSlotの返り値は、文法上は変数の場合も、スロットの場合もあり得る。
  ②しかし、addressOfSlotはresolveExprTypeからしか呼び出されない
  ③resolveExprTypeのaddressOfSlot以外（２，３，４）からの呼び出しの場合、必ずスロット（仮引数 or 返り値）のため、必ずスロットを返す。（OK）

２）callEvidence (Either String Evidence) から呼び出した時
  Callの場合のみRight それ以外はLeftなので、スロットだけを返す（OK）

３）collectEvidenceStmts (Either String (LocalEnv, Evidence)) から呼び出した時
  let a = xxx →変数 →LocalEnvのみ追加、Evidenceは追加しない（OK）
  return a →スロット（OK）
４）fnDeclEvidence から呼び出した時
  return a →スロット（OK）
