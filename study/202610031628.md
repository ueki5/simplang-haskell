[SlotResultの使われ方について(resolveExprTypeでのみ使用)]
  型 :Either String (Either Slot (Maybe Type))

ロジックだけを見ると、スロットだけでなく変数も混ざりそうに見えるが、名前からはスロット限定の型のはず。
そこで、「変数が混ざるケースは実際には呼び出されないのではないか？」という仮説を立て、
resolveExprTypeの呼び出し元を調査

１）addressOfSlot (Either String (Either Slot Type))
 resolveExprTypeの型：Either String (Either Slot (Maybe Type))
 自身の型           ：Either String (Either Slot        Type)
 Just (TPtr inner) → Right inner 
 Just _            → Left (ポインタ化できない)
 Nothing           → Left (型が未定義)
  ①addressOfSlotの返り値は、変数の場合も、スロットの場合もあり得る。
  ②addressOfSlotはresolveExprTypeからしか呼び出されない
  ③resolveExprTypeのaddressOfSlot以外（２，３，４）からの呼び出しの場合、必ずスロット（仮引数 or 返り値）のため、必ずスロットになる。（OK）

２）callEvidence (Either String Evidence)
  Callの場合のみRight それ以外はLeftなので、スロットしか返さない。（OK）

３）collectEvidenceStmts (Either String (LocalEnv, Evidence))
  let a = xxx →変数 →LocalEnvのみ追加、Evidenceは追加しない（OK）
  return a →スロット（OK）
４）fnDeclEvidence
  return a →スロット（OK）
