# 将来の課題（バックログ）

各 step の設計資料（`docs/stepXXX.md`）で「スコープ外」「将来の検討課題」とした事項を集約した一覧。step を追加するたびに更新する（新たに見送った課題は追記し、実現した課題は「実現済み」へ移す）。

- **出典**: その課題を記載している設計資料
- **難易度の目安**: 小＝既存の仕組みの延長で済む / 中＝新しい命令・構文が必要 / 大＝コード生成の前提や型システムの変更を伴う

## 1. 未着手の課題

### 1.1 制御構文・式

| 課題 | 出典 | 難易度 | 補足 |
|---|---|---|---|
| 値を返すブロック・`if`・`while`（`let x = if c {1} else {2};`） | step005, 006, 007, 008, 009 | 大 | 現在の `if`/`while` は文（Stmt）。式にすると、分岐の合流点で操作スタックの深さが揃うことを前提にしている `genBody` のアライメント計算に影響する |
| `for` 文 | step007, 008, 009 | 小〜中 | `while` への脱糖で実現できる見込み。範囲（`0..n`）の構文の要否が論点 |
| 比較のチェイン `a < b < c` を構文として禁止する | step008 | 小 | 現在は bool 同士の大小比較として型エラーになる |

### 1.3 型・演算

| 課題 | 出典 | 難易度 | 補足 |
|---|---|---|---|
| 配列の長さへの const の使用（`[i64; N]`、`[0; N]`） | step028 | 中 | 現在は型の要素数をパース時に数値で確定している。const の評価後に型を解決する仕組みが必要 |
| 不変の static と `static mut` の区別 | step028 | 大 | 現在の static は常に書き換え可能。ポインタの可変性（`&` / `&mut`）の区別とあわせて導入しないと、`&X` 経由の書き込みを防げない |
| ポインタ型の const | step028, 029 | 中 | const はメモリを持たない値として扱っているため。const のアドレス取得（`&N`）とあわせて検討する |
| import したソースの static のアドレスを初期値にする | step029 | 小〜中 | 現在、アドレスの定数に書けるのは同じソースの static だけ（定数式から参照できるのが同じソースの const だけであるのに揃えた）。アドレスはリンク時に解決されるので技術的には書ける |
| const のアドレス取得（`&N`） | step028 | 中 | 現在はエラー。Rust は const の値を読み取り専用の静的領域に置いた複製（定数の昇格）へのポインタにする。`&` と `&mut` の区別が無いと `*p = v` で書き換えられてしまうため、不変の static と `static mut` の区別とあわせて検討する。実現すれば `static P: &i64 = &N;` の初期値にも使える |
| const の配列 | step028 | 小〜中 | 添字アクセスのためにメモリが必要。現在は static の配列で代替できる |
| ブロック内・関数内での const/static の宣言 | step028 | 小〜中 | 現在はトップレベルのみ |
| 定数式から import したソースの const を参照する | step028 | 中 | import 先の const の評価に import をさらにたどる必要があり、ファイルをまたぐ循環の検出も要る |
| ビット演算・シフト | step018 | 小〜中 | 符号なし整数と相性が良い。算術右シフト／論理右シフトの使い分けが論点 |
| ポインタ演算（`p + 1`） | step012 | 中 | 現在は型エラーで拒否している。配列で添字アクセスができるようになったため、必要性は低下した |
| 検査付きの演算・変換（`checked_sub`/`try_from` 相当） | step018 | 中 | Option 型などの失敗を表す手段が必要 |
| 範囲外の型付きリテラル（`5000000000u32` 等）の検査・正規化 | step018 | 小 | 現在は `Push` の値がそのままスタックに載り、比較に直接使うと正しく比べられない |
| オーバーフローを実行時エラーにする | step018 | 中 | 言語全体の方針変更として、符号あり・なしの両方に適用する必要がある |
| ユニット型 `()` のゼロサイズ化 | step021 | 中 | 現在は bool と同じ32bitスロットに常に0を格納している。ゼロサイズにすると変数・ポインタ・配列・引数・式文で値が無いことの特別扱いが必要 |
